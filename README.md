#Kad-for-mg 

Этот проект я делал в лагере в августе 2024 года для платформы Discord*, когда онa ещё не был заблокирован Ркн. Суть проекта заключается в том, чтобы написать Discord* бота, который бы взаимодействовал через API с бесплатной версией нейронной сети Kadinsky от Сбербанка. Kadinsky - нейронная сеть для генерации изображений по описанию. Через Discord* можно было вводить промт и получать изображение в чат. Discord* был выбран в качестве платформы из за того, что в Telegram и Vk уже была возможность получать изображения через Kadinsky и при этом Discord* является популярной платформой. К сожаленю теоретичсекая часть ушла в небытие вместе с моим диском, но код бота остался. 

*Discord  запрещенный месенджер на територи Рф
